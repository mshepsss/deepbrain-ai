# DeepBrain AI — Game Design Document

**Date:** 2026-02-28

## Overview

DeepBrain AI is a turn-based web app simulation game where the player runs an AI company and races to achieve AGI before running out of money. Each turn represents one month. The player picks a starting role, makes strategic decisions, and reacts to AI industry events generated by Claude.

---

## Stack

- **Framework:** Next.js (TypeScript)
- **Styling:** Tailwind CSS — Soft Tech theme (light grey background, deep navy text, indigo/violet accents, rounded cards)
- **AI:** Anthropic SDK via Next.js API route
- **State:** React Context + localStorage persistence

## Game State

```typescript
type GameState = {
  month: number;
  cash: number;
  burnRate: number;
  revenue: number;
  agiProgress: number;       // 0–100
  researchPoints: number;
  headcount: {
    engineering: number;
    sales: number;
    operations: number;
  };
  role: RoleId;
  achievements: Achievement[];
}

type Achievement = {
  id: string;
  unlocked: boolean;
  bonus: StatModifier;
}
```

---

## Win / Lose Conditions

- **Win:** `agiProgress >= 100`
- **Lose:** `cash <= 0`

---

## Roles

| Role | Passive Bonus | Achievement Path |
|---|---|---|
| Head of Sales | +20% revenue/rep, -15% ramp time | Revenue milestones → unlock enterprise deals |
| CTO | +25% research speed, -10% eng hire cost | Hiring milestones → unlock senior engineer tier |
| CFO | 2x starting cash, -15% burn rate | Runway milestones → unlock investor relations events |
| Head of Research | +30% AGI progress/milestone, +10% compute cost | Research milestones → unlock breakthrough events |
| Growth Hacker | +25% user acquisition, early viral events | User milestones → unlock press coverage bonuses |

Each role has 3 achievements in its path. Achievements stack on top of role bonuses.

---

## Turn Structure

Each month the player:

1. **Receives a Claude-generated event** — AI news headline with 2–3 response options
2. **Makes up to 3 decisions** from:
   - **Hire** — Add staff to Engineering (+research points, +burn), Sales (+revenue, +burn), or Operations (-burn)
   - **Budget Allocation** — Slide % between R&D / Sales / Compute / Ops; Compute gates AGI progress speed
   - **Research Projects** — Spend research points on sequential milestones (e.g. "Train GPT-4 class model" → +15 AGI progress)
3. **Clicks "End Month"**
4. Stats update: `cash = cash + revenue - burnRate`
5. Win/lose check runs
6. Achievement check runs

The 3-decision limit forces monthly trade-offs.

## Claude Integration

**Route:** `POST /api/events`

**Request payload:**
```typescript
{
  month: number;
  cash: number;
  agiProgress: number;
  headcount: number;
  role: RoleId;
}
```

**Response schema:**
```typescript
{
  headline: string;
  flavourText: string;
  options: {
    label: string;
    effect: StatDelta;
    risk: string;
  }[];
}
```

**System prompt directives:**
- Base events on plausible real-world AI industry developments
- Scale event impact to current game month (early = small stakes, late = high stakes)
- Always return valid JSON matching the schema
